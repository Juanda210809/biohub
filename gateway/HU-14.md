# SCRUM-30 / HU-14: credencial y cuota

Rama: feature/SCRUM-30-credencial-cuota. Base: main.

Incluye configuracion y pruebas de API key por encabezado, ocultamiento de la clave
al upstream y cuota de 60/minuto por consumidor. Dos claves del mismo consumidor
comparten cuota. La peticion 61 recibe 429 con Retry-After sin llegar al upstream;
un segundo consumidor conserva su cuota. Se bloquea el acceso alternativo por
/api/v1/consulta/externa para que no permita evadir estos controles.

Ejecutar con Docker activo desde la raiz:

    python -m pip install -r gateway/requirements-test.txt ruff
    ruff check gateway/tests
    python -m pytest gateway/tests -q -W error

La clave clave-demo-universidad es solo de demostracion. Se envia en el encabezado
apikey a /externa/v1/hallazgos. URL y cuerpo no autentican. Una sola instancia de Kong
usa contadores locales; multiples instancias requieren contadores compartidos.

Las pruebas usan Kong real y un upstream de prueba. No certifican el inventario,
coordenadas en su respuesta, despliegue publico ni resistencia a carga masiva.
Esos pendientes no se declaran terminados por esta entrega.
